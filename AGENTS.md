# Projeto

Site institucional em React 19 + Vite + TypeScript, com Tailwind CSS v4 (`@tailwindcss/vite`),
React Router (`react-router-dom`) e framer-motion. Não usa mais Next.js.

- Entrada: `index.html` → `src/main.tsx` → `src/App.tsx` (rotas)
- Páginas em `src/pages/`, seções da home em `src/sections/`, componentes em `src/components/`
- Alias `@/` aponta para `src/`
